# Changelog

## 0.2.0 — development preview

- Connect personal Outlook and Microsoft 365 accounts with Microsoft device sign-in; keep tokens in macOS Keychain.
- Sync inboxes, rank mail locally, archive, mark read, snooze locally, and reply with a cancel window.
- Open the notch panel from the camera area even when no notification is visible; show a useful empty state.
- Anchor the panel to the camera geometry, prevent menu-bar frame clamping, and size notification stacks to their content.
- Add original macOS app artwork at all icon resolutions and an About tab with version/build information.
- Use VERSION as the default package version and retain GitHub run numbers for build identification.

Microsoft publisher registration and live mail testing remain outstanding. Hardware hover/full-screen validation is tracked in docs/qa/NOTCH-2026-11-17.md. Downloads are ad hoc signed, not notarized. Updates are downloaded manually from GitHub; there is no automatic updater.
